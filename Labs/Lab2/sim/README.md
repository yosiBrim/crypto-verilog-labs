# Behavioral Simulation (Lab 2)

## Overview
This directory contains the functional verification results for the Counter, Decoder, and MUX design. The simulation was performed to validate the RTL logic against the defined Acceptance Test Plan (ATP).

## Acceptance Test Plan (ATP) Execution
The testbench (`tb_lab_2.v`) stimulates the design with the following sequence:
1. **0ns - 100ns:** Initialization. The `reset` signal is driven high to initialize the synchronous counter.
2. **100ns - 360ns:** Normal counting mode. `reset` is de-asserted. The `sel` signal is driven low (`0`), routing the raw counter output (`Q`) directly to the system output (`y`).
3. **360ns onwards:** Decoder evaluation mode. The `sel` signal is driven high (`1`). The MUX switches to route the 4-bit decoded output (`Detect`) to the system output (`y`), validating the combinational decoding logic mid-cycle.

## Files
* **`rtl_simulation.png`**: Waveform viewer capture demonstrating the correct transition of states, the counter's incrementation, and the multiplexer's switching behavior.
* **`transcript.png`**: The console output generated by the `$monitor` system task. It captures real-time signal changes, utilizing Verilog Cross-Module References (XMR) to monitor internal design signals (`DUT.Q` and `DUT.Detect`) alongside the top-level ports.
