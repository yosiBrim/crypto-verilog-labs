# Lab 4 Documentation - DES Algorithm Implementation

This folder contains the formal documentation and requirements for the DES (Data Encryption Standard) implementation lab.

## Contents
* **Lab Requirements:** Formal PDF describing the hardware design goals and constraints.
* **Design Specifications:** Details regarding the permutations (IP, FP, E-Bit), S-Boxes, and Key Schedule.
* **Verification Reports:** Summary of simulation results and hardware utilization from Vivado.

## Lab Objectives
The goal of this lab was to implement a full DES encryption cycle using Verilog, focusing on:
1. Combinational logic for permutations and S-Box substitutions.
2. Synchronous logic for the 16-round Feistel network.
3. Hardware optimization for Artix-7 FPGA (Basys3).
